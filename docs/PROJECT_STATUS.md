## 🔧 当前状态

### PDF 真题提取遇到的问题
1. **PDF 是扫描版**：每页都是图片，无法直接提取文本
2. **OCR 方案复杂**：
   - pdf2image 需要 poppler（Windows 安装复杂）
   - DeepSeek API 不支持图片输入
   - 专业 OCR 工具（Tesseract）对日语支持一般

### 推荐解决方案

**方案 A：先上线，后续补充数据**（推荐）
1. 使用现有 10 题示例数据
2. 先把网站功能完善并部署上线
3. 真题数据后续慢慢补充（手动录入或外包）

**方案 B：使用在线 OCR 服务**
- 百度 OCR API（支持日语）
- 阿里云 OCR
- Google Cloud Vision API

**方案 C：手动录入**
- 找人手动录入（最准确）
- 预计时间：1-2 周
- 成本：约 ¥500-1000
