## 🎯 核心任务清单

### Phase 1: PDF 解析与数据导入（优先级：最高）

#### 1.1 选择 PDF 解析方案

**方案对比**：

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **Stirling PDF** | 功能全面，支持 OCR、格式转换 | 需要 Docker 部署，较重 | ⭐⭐⭐ |
| **pdf2json** | 轻量，npm 安装即用 | 对扫描版 PDF 效果差 | ⭐⭐ |
| **AI 辅助（DeepSeek/Claude）** | 智能识别题目结构 | 需要 API Key，有成本 | ⭐⭐⭐⭐⭐ |
| **手动录入** | 准确度最高 | 耗时巨大（1980 题） | ⭐ |

**推荐方案**：**AI 辅助 + 人工校对**
- 使用 DeepSeek API（成本低，中文友好）批量解析 PDF
- 提取题目、选项、答案
- 人工校对关键信息（答案、解析）
- 批量导入数据库

#### 1.2 实现步骤

```bash
# 1. 配置 DeepSeek API Key
echo "DEEPSEEK_API_KEY=your_key_here" >> .env.local

# 2. 批量解析 PDF（按年份）
npm run parse-pdf -- --year 2025 --month 12
npm run parse-pdf -- --year 2025 --month 07
# ... 依次处理 2020-2025 年真题

# 3. 人工校对
# 检查 parsed-questions-{year}-{month}.json
# 修正错误

# 4. 批量导入数据库
npm run import-exam -- --file parsed-questions-2025-12.json
```

**预计时间**：
- PDF 解析：2-3 天（AI 自动化）
- 人工校对：5-7 天（每套约 180 题）
- 数据导入：1 天

## 🛠️ 技术栈总结

### 现有技术栈
- **前端**：Next.js 14 + React 18 + TypeScript
- **样式**：Tailwind CSS + Framer Motion
- **数据库**：腾讯云开发（CloudBase）
- **AI**：DeepSeek API
- **部署**：待定（推荐 Vercel）

### 新增工具（可选）

#### x-crawl（网页爬虫）
- **用途**：爬取在线词汇库、语法资源
- **安装**：`npm install x-crawl`
- **使用场景**：补充词汇解释、例句

#### Stirling PDF（PDF 处理）
- **用途**：PDF OCR、格式转换
- **部署**：Docker
- **使用场景**：处理扫描版 PDF

#### Dataflow（PDF 图文匹配）
- **用途**：精准提取 PDF 中的图文内容
- **部署**：需要下载 GitHub 仓库
- **使用场景**：处理包含图表的阅读题
