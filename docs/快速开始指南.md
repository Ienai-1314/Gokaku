## 推荐方案：百度OCR API

### 为什么选择百度OCR？

1. **成本低**：185个PDF只需¥5.5，每月还有1000次免费额度
2. **准确率高**：专门优化过日语识别，准确率95%+
3. **速度快**：2-3小时完成所有PDF提取
4. **简单易用**：Python SDK支持好，代码已准备

### 申请步骤（10分钟）

1. **注册百度智能云**
   - 访问：https://cloud.baidu.com/
   - 使用手机号注册

2. **开通文字识别服务**
   - 进入控制台：https://console.bce.baidu.com/ai/#/ai/ocr/overview/index
   - 点击"立即使用"
   - 创建应用

3. **获取API密钥**
   - 在应用管理页面查看：
     - APP_ID
     - API_KEY
     - SECRET_KEY

4. **配置到脚本**
   ```bash
   # 编辑文件
   notepad C:\Users\Garo\gokaku\scripts\extract_with_baidu_ocr.py
   
   # 填入密钥
   APP_ID = '你的APP_ID'
   API_KEY = '你的API_KEY'
   SECRET_KEY = '你的SECRET_KEY'
   ```

5. **开始提取**
   ```bash
   cd C:\Users\Garo\gokaku
   python scripts\extract_with_baidu_ocr.py
   ```

## 需要帮助？

### 常见问题

**Q: 百度OCR识别效果不好怎么办？**
A: 切换到腾讯云OCR或阿里云OCR，API接口类似

**Q: DeepSeek解析失败怎么办？**
A: 检查API Key配置，或手动修复JSON格式

**Q: 答案补充太慢怎么办？**
A: 优先补充词汇和语法题（10题），其他题目后续补充

**Q: 数据库导入失败怎么办？**
A: 检查数据格式，运行验证脚本找出问题
