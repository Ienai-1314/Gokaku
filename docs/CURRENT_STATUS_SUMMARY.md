## 🔧 技术方案

### PDF 处理流程
```
PDF 扫描版
  ↓
MinerU API (OCR)
  ↓
Markdown 文本
  ↓
DeepSeek API (结构化)
  ↓
JSON 题目数据
  ↓
CloudBase 数据库
```

### 关键工具和脚本
1. **classify_pdfs.py** - PDF 智能分类（8种类型）
2. **batch_extract_final.py** - 批量提取（DataFlow + MinerU）
3. **parse_classified_questions.py** - DeepSeek 解析（需优化）
4. **import_questions.ts** - 数据库导入
